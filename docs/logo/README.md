# rang-core logo

The mark is an interferogram: a round aperture filled with fringe bands that
fade toward the rim, and one point, the source the interferometer recovers.
The wordmark reads `rang`, a fringe, `core`: its hyphen is a single fringe.

Colours: ink `#10131a`, white, amber `#e8a33d`. Nothing else.

| File | Use |
| --- | --- |
| `logo.svg` | the mark, 512 px, for pages and large placements |
| `icon.svg` | coarser fringes for app icons and avatars, 16 to 256 px |
| `icon-mono.svg` | monochrome icon for favicons and print |
| `wordmark.svg`, `wordmark-on-dark.svg` | the name alone |
| `lockup.svg`, `lockup-on-dark.svg` | mark plus name, for the README and the docs header |

The wordmark uses Inter (fallbacks Helvetica Neue, Segoe UI, Arial); convert
to outlines before placing it where fonts cannot be relied on. PNG and ICO
renders are produced by the documentation build.
