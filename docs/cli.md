# Command line

`rang-core` (also `python -m rang.core_cli`) is one command line for every
archived chain: `rang-core STAGE VERB ARGS...` ({gh}`research/p9-cli.md`).
Each stage has `run` (the driver), `compare` (one comparator engine: the
verdict and counts against an archive) and `archive` (a versioned
`rang.archive` file); `rang-core check` runs the full local checks on any
platform. Every call writes a receipt, `<output>.<verb>.rang-receipt.json`
(schema `rang.receipt` version 2: the command, its inputs, the environment
and the commit), unless `--no-receipt` is given. The OpenBLAS, OpenMP, MKL
and XLA thread pools are capped at one thread where their variables are
unset, unless `--no-pin-threads` is given or `RANG_PIN_THREADS=0` is set;
`RAYON_NUM_THREADS` sets the core's own threads.

The core-native Stimela2 recipes `recipes/core-*.yaml` call the same
functions. Most stages replay a frozen campaign and need its archived inputs
under `outputs/`; the stage help and the linked reports say which.

This page is generated by `docs/gen_cli.py` from the help texts below and
checked against them by the test suite.

## Overview

```text
$ rang-core -h
usage: rang-core [--receipt PATH | --no-receipt] [--no-pin-threads] STAGE VERB ARGS...

stages and verbs:
  injections      run | compare | archive
                  injection campaign (research/core-phase3.md)
  actions         run | compare | archive
                  patch-removal actions stage (research/core-phase3-actions.md)
  prospective     run | compare | archive
                  prospective track (research/core-phase3b.md)
  signal          run | compare | archive
                  signal track (research/core-phase3c-b.md)
  trend           mirror | run | compare | archive
                  trend track on a core-solved mirror (research/core-phase3-trend.md)
  imaging         run | replay | compare | archive | legacy-archive
                  imaging track replay, task I (research/core-i-imaging-replay.md)
  campaign        run | precondition | compare | archive | legacy-archive
                  LUNO campaign, task K (research/core-k-luno-campaign.md)
  campaign-array  run | precondition | compare | archive | legacy-archive
                  LUNO whole-array campaign, task L1 (research/luno-array-campaign.md)
  campaign-1830   fetch | run | precondition | compare | archive | legacy-archive
                  PKS 1830 campaign, task L2 (research/luno-1830-campaign.md)
  campaign-fieldmodel fetch | run | compare | archive | legacy-archive
                  PKS 1934-638 field-model arms, task L1-M (research/l1-model-completeness.md)
  wgridder        compare | archive
                  exact w-gridder ported from ducc0, task DF1 (research/df1-wgridder.md)
  flags           run | compare | archive
                  Tricolour strategies, task D (research/core-d-tricolour.md)
  weights         compare
                  imaging weights and Stokes I, task B (research/core-b-weighting.md)
  gridder         run | compare | archive
                  w-stacking gridder, task C (research/core-c-gridder.md)
  ms              compare
                  Measurement Set reader, task E (research/core-e-ms-reader.md)
  section6        run | compare | archive
                  zarr-to-survey chain (research/core-section6.md)
  backends        compare
                  two suite directories, file by file (research/core-j-packaging.md)
  bench           f | p1 | p2 | p3 | p4 | p5 | p6
                  benchmarks (research/core-f-performance.md, p1-p6)

other commands:
  environment     RUN_DIR: record the interpreter and the frozen solver's absence
  check           [--rust | --python | --all]: the full local checks, portable
  compare         STAGE RESULT ORACLE RECEIPT: legacy form (adds `comparator`)
  trend-mirror    MIRROR SOURCE: legacy form of `trend mirror`

`rang-core STAGE -h` describes a stage's verbs. `compare` takes the
arguments of examples/compare_core_<stage>.py or of the stage's checker.
```
