## CLEAN theory programme

- [gemclean](gemclean.md), a reference CLEAN with an exact image-domain value per step, a binary and an optimisation log: minor cycles must stop at the measured pointwise error or they fit the beam's off-centre error (20 Jy of false flux on S1, found by the benchmark). Then 4-5 major cycles at WSClean's false flux; 1-3 is not reachable. All times provisional.
- [A many-pass solver over the Gram operator](gram-solver.md): a speed gain only against FISTA on the exact gridder, none against a PSF inner loop with exact passes or against CLEAN; lower false flux than CLEAN at much higher cost.
- [A theorem for gemclean's stop rule](stop-rule-theorem.md): a rule's consequences are proved in Lean for any valid bound on the beam error (true sign and size at the pick, descent, no flux below the level, flux per pixel); the bound, on paper plus a measured gridder term, is 3-7 times the exact column maximum per entry. It costs 10-17 major cycles against the default's 4-5 at the same false flux, so it is not the default. The measured `δ` is not a bound: 100 Jy at the phase centre sends the default to its component budget with 50.6 Jy of false flux.
- [GeMClean memory on joined polarisations](gemclean-memory.md) (issue #32, 2026-11-15; implemented, measured): accounting first, then fixes at byte-identical output; joined IQUV 8-channel 2048² on J1833−2103 from 20.24 to 9.20 GiB (WSClean 1.34 GiB); a peak-heap regression test.
- [GeMClean memory, phase 2](gemclean-memory2.md) (issue #32, 2026-11-16; implemented, measured, partly met): `-reorder` keeps the read and the visibilities in temporary files, byte-identical; tree RSS J1331+3030 15.87 → 9.12 GiB, J1939−6342 16.46 → 9.10 (met), J1833−2103 8.40 → 7.17 (not met, 0.854 against 0.75); WSClean 1.3-2.0 GiB.

- [Sky uncertainty](sky-uncertainty.md): 2% off-axis flux errors raise pointing RMSE from 2.40 to 30.24 arcsec when calibration holds the sky fixed.
- [Information budget](information-budget.md): separates unconstrained visibility information from what uncertain external flux constraints supply.
- [katbeam pointing](katbeam-pointing.md): chromatic beam shape supplies pointing information in the simulation; a measurement-informed scalar model, not complete measured antenna Jones beams.
- [Uncertainty coverage](uncertainty-coverage.md): local Gauss–Newton marginal uncertainties and a beam-width recovery control.
- [Robustness stress](robustness-stress.md): simulated controls showing the matched-model result is not sufficient.
- [Frequency blocking](frequency-blocking.md): standard structured least-squares elimination, a compute benchmark and not an end-to-end calibrator speedup.
- [Public pointing history](pointing-history.md): an inspection of the SARAO release (CC BY-NC 4.0), kept in ignored outputs.
- [Calibration research, 2026-09-11](calibration-research-2026-09-11.md): the first literature review and candidate method, superseded by the [MeerKAT scope](meerkat-scope.md).
- [Message draft](sharing-draft.md): an unsent note to Oleg Smirnov, kept for the record.

**Scope of those simulations.** Main experiments use eight approximate MeerKAT
core positions, scalar beams, four frequencies and a small component sky
([geometry and provenance](../data/README.md)). The DFT includes the non-coplanar
phase. The JAX solver supports smooth pointing, source fluxes/spectral indices,
complex gains and selected beam parameters; it is a reference implementation,
not a streaming or full-polarization pipeline. The katbeam adapter provides a
simplified holography-informed scalar response. A public Measurement Set reader
has been exercised, but antenna-label and pointing-coordinate conventions remain
unresolved. The pointing demonstrator does not establish real-observation
pointing calibration or improved deconvolved images. Actual QuartiCal gain solves
in the separate flagging pilots are visibility-space research diagnostics.
Structured projection benchmarks are not end-to-end calibrator speedups.
